# Interface conventions

Use the local CSS tokens and shared Thymeleaf shell. Keep a white workspace,
restrained accent color, readable table rows and clear form labels. The workspace
has one page heading followed by task, execution, snapshot and delivery sections.

Use 14px body text, 20px section headings and a 24px page heading. Controls use
shared styles, a 4px radius and a visible keyboard focus ring. On narrow screens
or coarse pointers, interactive controls have at least 44px height. Allow navigation
to wrap and tables to scroll inside their container. Values and identifiers must
wrap without clipping. Keep error messages fixed and omit exception details.

Assets are local text sources only. Use semantic HTML, labeled inputs, captions,
scope attributes for table headers, a skip link and explicit empty states.
